# Faculty Attendance Management System

A web-based attendance management system built for faculty, enabling rapid daily attendance marking, course management, history editing, and reporting.

## Stack
- React 18
- Vite 5
- Supabase (PostgreSQL + Auth)
- Tailwind CSS 3
- React Router DOM 6
- React Hook Form + Zod

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the dev server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
